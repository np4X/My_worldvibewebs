This thing mostly my vibe coded website

## Electrical notes & diagrams

- LaTeX lecture notes live under `<CourseName>_<CourseCode>/Chapter_XX/*.tex` (e.g. `Circuits1_2301XXX/Chapter_01/notes.tex`).
- Circuit diagrams (draw.io source) live in the shared `Circuits_elements/` folder, reused across chapters.
- PDFs and PNGs are **auto-generated by GitHub Actions** on push (`.github/workflows/render-latex.yml`, `.github/workflows/render-drawio.yml`). Don't hand-edit the generated `.pdf`/`.png` files — edit the `.tex`/`.drawio` source instead and let CI re-render them.
