## Electrical notes & diagrams

- LaTeX lecture notes live under `<CourseName>_<CourseCode>/*.tex` (e.g. `POWER_E_466/notes.tex`), or nested in `Chapter_XX/` subfolders per course if that course has multiple chapters worth splitting out. Figures are inserted as blank placeholders (`\blankfig`) for now, filled in by hand later — circuit diagrams built directly in `.tex` with `circuitikz` didn't work out.
- PDFs are **auto-generated by GitHub Actions** on push (`.github/workflows/render-latex.yml`). Don't hand-edit the generated `.pdf` files — edit the `.tex` source instead and let CI re-render them.
- `Circuits_elements/` holds example draw.io diagrams (`circuit_elements.drawio`, `buck_converter.drawio`) and a shape-name reference kept for occasional manual use — no longer auto-rendered by CI.
